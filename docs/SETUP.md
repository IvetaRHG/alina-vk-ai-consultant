## 1. Требования

- Python **3.10+** (рекомендуется 3.11–3.13).
- Аккаунт в **GigaChat Studio** и доступ к GigaChat API.
- Сообщество ВКонтакте, в котором вы администратор.
- Корневые сертификаты **НУЦ Минцифры** (нужны для GigaChat API) **или**
  `GIGACHAT_VERIFY_SSL=false` для локальной проверки.

## 2. Установка

### Windows (PowerShell)

```powershell
git clone https://github.com/IvetaRHG/alina-vk-ai-consultant.git
cd alina-vk-ai-consultant
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Linux / macOS

```bash
git clone https://github.com/IvetaRHG/alina-vk-ai-consultant.git
cd alina-vk-ai-consultant
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 3. Ключ GigaChat API

1. Зарегистрируйтесь в **GigaChat Studio**: <https://developers.sber.ru/studio>
2. Создайте проект **GigaChat API**.
3. Откройте проект → **Настройки API** → **«Получить ключ»**.
4. Сохраните значения:
   - **Authorization Key** — это `GIGACHAT_AUTH_KEY`;
   - **Client ID** и **Client Secret** — пригодятся, если понадобится
     перевыпустить ключ.
5. Ключ и секрет показываются **только один раз**. Потеряли — генерируйте новый.
6. Пополните баланс или подключите тариф, иначе запросы будут отклоняться.

### Какой scope выбрать

| Scope | Для кого |
|---|---|
| `GIGACHAT_API_PERS` | Физические лица |
| `GIGACHAT_API_B2B` | ИП и юрлица по платным пакетам |
| `GIGACHAT_API_CORP` | ИП и юрлица по схеме pay-as-you-go |

Если не уверены — оставьте `GIGACHAT_SCOPE` пустым, бот использует
`GIGACHAT_API_PERS`.

## 4. Сертификаты Минцифры

GigaChat API использует сертификаты НУЦ Минцифры. Без них возможна ошибка:

```
[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed
```

Три варианта решения:

**А. Установить в ОС (рекомендуется).** Скачайте корневые сертификаты на
портале Госуслуг: <https://www.gosuslugi.ru/crt> и установите в системное
хранилище.

**Б. Указать путь к файлу.** Положите сертификат в папку `certs/` и пропишите:

```env
GIGACHAT_CA_BUNDLE=certs/russian_trusted_root_ca_pem.crt
```

Относительный путь считается от корня проекта.

**В. Отключить проверку (только локально).**

```env
GIGACHAT_VERIFY_SSL=false
```

Не используйте этот вариант на сервере: он снижает безопасность соединения.

## 5. Настройка сообщества ВКонтакте

1. Откройте сообщество → **Управление**.
2. Включите **«Сообщения сообщества»** и **«Возможности бота»**:
   **Управление → Сообщения → Настройки для бота**.
3. Перейдите в **Управление → Дополнительно → Работа с API**
   (в новом интерфейсе — **Настройки → Работа с API**).
4. Создайте **ключ доступа** с правом **«Сообщения сообщества»**
   (при необходимости — «Управление сообществом»). Это `VK_TOKEN`.
5. Включите **Long Poll API** и добавьте событие **«Входящее сообщение»**
   (`message_new`).
6. Узнайте **числовой ID сообщества** — это `VK_GROUP_ID` **без минуса**.

> Если ID сообщества `-123456789`, в `.env` укажите `123456789`.
> Используйте ключ сообщества, а не личный токен пользователя: личный токен
> не подходит для сообщений сообщества.

## 6. Ссылка на форму заявки

Создайте форму (Яндекс Формы, Google Forms, Tilda, CRM) и вставьте ссылку в
`SALES_FORM_URL`. Бот покажет её кнопкой **«Оставить заявку»** и будет
предлагать в подходящий момент диалога.

Если ссылки нет — оставьте переменную пустой: бот не придумает URL, а
предложит контакт менеджера из `MANAGER_CONTACT`.

## 7. Переменные окружения

```powershell
Copy-Item .env.example .env      # Windows
cp .env.example .env             # Linux / macOS
```

| Переменная | Обязательна | По умолчанию | Назначение |
|---|---|---|---|
| `VK_TOKEN` | Да | — | Ключ доступа сообщества с правом «Сообщения сообщества». |
| `VK_GROUP_ID` | Да | — | Числовой ID сообщества **без минуса**. |
| `GIGACHAT_AUTH_KEY` | Да | — | Authorization Key из GigaChat Studio. |
| `GIGACHAT_SCOPE` | Нет | `GIGACHAT_API_PERS` | Версия API под тип аккаунта. |
| `GIGACHAT_MODEL` | Нет | `GigaChat-2` | Модель: `GigaChat-2`, `-Pro`, `-Max`. |
| `GIGACHAT_BASE_URL` | Нет | `https://api.giga.chat/v1` | Базовый адрес API. |
| `GIGACHAT_OAUTH_URL` | Нет | `https://ngw.devices.sberbank.ru:9443/api/v2/oauth` | Получение access token. |
| `GIGACHAT_VERIFY_SSL` | Нет | `true` | Проверка SSL. `false` — только локально. |
| `GIGACHAT_CA_BUNDLE` | Нет | — | Путь к PEM/CRT сертификату Минцифры. |
| `SALES_FORM_URL` | Желательно | — | Ссылка на форму заявки (кнопка в диалоге). |
| `MANAGER_CONTACT` | Нет | `care@zerocoder.ru, +7 (939) 328-38-12` | Контакт для передачи менеджеру. |
| `MAX_HISTORY_MESSAGES` | Нет | `12` | Сколько сообщений диалога отправлять в модель. |
| `LOG_LEVEL` | Нет | `INFO` | `DEBUG`, `INFO`, `WARNING`, `ERROR`. |

Пример заполненного `.env` (значения вымышленные):

```env
VK_TOKEN=ваш_ключ_сообщества
VK_GROUP_ID=123456789
GIGACHAT_AUTH_KEY=ваш_authorization_key
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2
GIGACHAT_VERIFY_SSL=true
SALES_FORM_URL=https://example.com/form
MANAGER_CONTACT=care@zerocoder.ru
```

> **Никогда не публикуйте `.env`** и не вставляйте ключи в код, скриншоты,
> чаты и коммиты. Файл уже добавлен в `.gitignore`.

## 8. Запуск

Из **корня проекта** (там, где лежат `src/`, `data/`, `prompts/`):

```bash
python -m src
```

На Windows без активации окружения:

```powershell
.\.venv\Scripts\python.exe -m src
```

При успешном запуске в логах будет:

```
=== Бот Алина запускается ===
Модель GigaChat: GigaChat-2
Подключение к ВК успешно. Сообщество: ...
GigaChat: авторизация успешна
Слушаю сообщения сообщества...
```

Напишите сообществу ВКонтакте — бот должен ответить. Остановка: `Ctrl+C`.
Лог дублируется в файл `bot.log` в корне проекта (UTF-8).

## 9. Проверка и типовые ошибки

### `CERTIFICATE_VERIFY_FAILED`

Не установлены сертификаты Минцифры. См. [раздел 4](#4-сертификаты-минцифры).

### `GigaChat отклонил ключ авторизации (HTTP 401)`

- Ключ скопирован не целиком.
- Неверный `GIGACHAT_SCOPE` (для физлица — `GIGACHAT_API_PERS`).
- Ключ отозван или на проекте закончились токены.

### `HTTP 403` или бот не видит сообщения

- Не включены «Сообщения сообщества».
- У ключа нет права «Сообщения сообщества».
- `VK_GROUP_ID` указан с минусом или от другого сообщества.
- Не включён Long Poll API или событие `message_new`.

### Бот молчит

- Смотрите `bot.log`: ошибки GigaChat и VK пишутся туда.
- Сообщение отправлено в сообщество, а не в личные сообщения от вашего имени.
- Long Poll не отключён, бот запущен.

### `HTTP 429` от GigaChat

Исчерпаны лимиты или токены. Бот делает до трёх повторов, но при постоянной
ошибке проверьте баланс и лимиты проекта.

### Кракозябры в консоли Windows

```powershell
chcp 65001
$env:PYTHONUTF8="1"
```

### Ответ длиннее 4096 символов

ВКонтакте ограничивает длину сообщения. Бот сам делит ответ на части — это
штатное поведение, ничего настраивать не нужно.
